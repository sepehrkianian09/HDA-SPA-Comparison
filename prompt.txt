
I want to do an experiment.

I am comparing the usefulness of two web development paradigms: SPA and HDA.

For that purpose, I want to do an experiment. I want to develop web applications for different domains using these paradigms, and compare them. Then, I want to compare those applications using predefined metrics. The metrics can be in terms of code maintainability and lighthouse metrics for the UI. It is also good to mention that I want to use the same backend for those, and also have tests (both unit and playwright) to ensure the workability of those web application.

Help me with this. I recommend following this process:

1. Figuring out the metrics for the web applications.

2. Figuring out the best backend stack for this.

3. Figuring out the domain of focus (e.g. E-commerce, very stateful applications)

4. Doing a requirements engineering analysis.

5. Creating Scenarios

6. Developing two separate applications

7. Gathering metrics

Moreover, here is the literature review of mine, which might come in handy. 

// SPA in practice
This page (https://a11y-guidelines.orange.com/en/articles/single-page-app/) has some recommendations for implementing SPAs.

Next.js (https://nextjs.org/docs/app/guides/single-page-applications), a Meta-framework implementation techniques combining SSR and client hydration, can be used for implementation, if beneficial.

This article (https://aaltodoc.aalto.fi/server/api/core/bitstreams/9228e471-cada-4f3f-97de-008d39a1c65c/content) showcases using SSR to eliminate SPA cold-start latency and SEO barriers.

This article (https://doi.org/10.1145/3267183.3267190) showcases Isomorphic JavaScript and pre-rendering techniques to improve SPA initial load.

This article (https://ieeexplore.ieee.org/abstract/document/10247348) showcases Empirical implementation techniques for isomorphic rendering in SPAs.

// HDA knowledge
This article (https://htmx.org/essays/hypermedia-driven-applications/) showcases Core principles of Hypermedia-Driven Architecture and HATEOAS.

This article (https://htmx.org/essays/you-cant/) showcases Refuting SPA necessity by detailing HDA capabilities for interactive apps.

This article (https://hda.daz.is/architecture/why-hypermedia-driven-architecture/) showcases Architectural rationale and simplified state model of HDA vs SPA.

This article (https://arxiv.org/pdf/2602.17193) showcases HTML-First philosophy as the foundation for modern HDA web development.

// HDA in practice
This article (https://pmc.ncbi.nlm.nih.gov/articles/PMC10582517/)showcases Implementation technique using hypermedia controls to streamline TDD testing.

This article (https://aaltodoc.aalto.fi/server/api/core/bitstreams/23619032-8609-4ec1-992d-bce688ad3bb7/content) showcases State serialization and resumability primitives to enhance server-driven application startup.

This article (https://arxiv.org/pdf/2304.01947) showcases Zero-JS compiler techniques (Qwik, Astro) to optimize HTML-first server execution.
